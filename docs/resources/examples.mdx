title: Examples
description: What each example in the repository is, and which ones are not a public SDK.
---

The examples live in the [larkxai/larkx](https://github.com/larkxai/larkx) repository.

| Example                                                                                                 | What it is                                                                                                                               |
| ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| [examples/react-native-agent](https://github.com/larkxai/larkx/tree/main/examples/react-native-agent)   | Field-inspection demo: local tools, optional Cactus, LangGraph over A2A, and Cloud telemetry. It is an application, not the SDK package. |
| [examples/remote-task](https://github.com/larkxai/larkx/tree/main/examples/remote-task)                 | HTTP task fixture used by tests. Not a hosted product.                                                                                   |
| [examples/a2a-fixture](https://github.com/larkxai/larkx/tree/main/examples/a2a-fixture)                 | A2A 1.0 failure-injection peer. Not a LangGraph agent.                                                                                   |
| [examples/langgraph-a2a-agent](https://github.com/larkxai/larkx/tree/main/examples/langgraph-a2a-agent) | Independently deployed LangGraph agent with an A2A 1.0 endpoint.                                                                         |
| [examples/node-agent](https://github.com/larkxai/larkx/tree/main/examples/node-agent)                   | Private Node host: scripted agent, local tools, SQLite, and process termination.                                                         |
| [examples/node-hybrid](https://github.com/larkxai/larkx/tree/main/examples/node-hybrid)                 | Private Node host delegating over HTTP or A2A. Not a public SDK.                                                                         |
| [examples/swift-agent](https://github.com/larkxai/larkx/tree/main/examples/swift-agent)                 | A small Swift program that calls the C ABI. It is not a Swift SDK.                                                                       |

Node process-death tests stop `examples/node-agent` or the hybrid example with `SIGKILL` and reopen the database. Those tests are not an iOS or Android device run.

Start with the [quickstart](/getting-started/quickstart) if you want the smallest program that uses the published package.
